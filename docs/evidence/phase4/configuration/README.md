Unit and CLI process cases exercise option/environment precedence, absence of implicit provider
selection, local credential isolation, invalid models/keys/URLs/budgets, attacker hostnames and
key-free undecorated JSON inspection. The runtime leaves startup identities unresolved until
settings pass parsing, so invalid model strings do not enter trusted trace fields.

The configuration browser suite builds a planner through the explicit local factory and drives
Chromium to a synthetic fact. The loopback HTTP server asserts the configured synthetic local key
and a durable crossing before each request. The final answer must cite exact captured evidence.
Invalid local hosts, invalid models, unavailable Anthropic and the production accounting lock
produce failed traces without creating a browser profile or sending another model request.

[Raw event logs](runs/) retain each report's run IDs. `evidenceDir` identifies the original local
attempt; this archive replaces that temporary prefix with source/built case directories. Runtime
regression logs include suspended, uncertain, stopped and deliberately failed cases. The deliberate
storage-failure regression has no trace because saving is the operation under test. Reopened runs
share the original pending log. The corrupt-tail regression intentionally includes an invalid tail.
All fixtures use synthetic data. Source imports resolve through the root TypeScript configuration;
compiled runs use built package entry points. No source was edited during the final suites.

The constructed fixture planner is trusted injected test code and intentionally bypasses the
production accounting lock. It is a synthetic HTTP service, not an actual local inference model.
No server reachability, model quality, current hosted pricing, signed-in/held-out site readiness
or full TUI is established. Hosted CI results are reported separately on the PR. Historical
Phase 2 credential/safety and gate-mutation artifacts were not regenerated by this slice; the
inherited baseline and Phase 3 lifecycle suite were rerun. See [PHASE4.md](../../../PHASE4.md)
for the selection contract and remaining gate.
